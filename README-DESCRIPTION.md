# Описание системы

| Раздел | Что находится | Зачем нужен |
| --- | --- | --- |
| Dashboard | Сводные показатели и графики | Быстро посмотреть состояние всей системы: сколько рейсов, машин, водителей, бронирований и т. д. |
| Vehicles | Автомобили: тип, регистрационные данные, статус и доступность | Управление автопарком и выбор машины для рейса |
| Drivers | Водители, лицензии, контакты, статус | Понимать, кто из водителей доступен и кому назначить рейс |
| Routes | Заранее определённые маршруты: откуда → куда, расстояние, расчётное время | Не создавать маршрут заново для каждого рейса |
| Trips | Конкретные рейсы | Связывает машину + водителя + маршрут и отслеживает жизненный цикл рейса |
| Bookings | Клиентские бронирования | Клиент бронирует место/перевозку на конкретный рейс |
| Lorry Receipts | Транспортные накладные / документы на груз | Фиксируется груз: отправитель, получатель, откуда, куда, вес, количество, статус |
| Expenses | Расходы на поездки и транспорт | Топливо, платные дороги, обслуживание, выплаты водителю и т. п. |
| Invoices | Счета | Можно сформировать счёт, в том числе автоматически на основании расходов рейса, а затем выгрузить PDF |
| Reports | Отчёты по рейсам, машинам и водителям | Анализ работы системы и выгрузка данных, в том числе CSV |
| Fuel Analytics | Аналитика топлива | Расход топлива, стоимость на километр, расходы по автомобилям и периодам |
| Geofences | Виртуальные зоны на карте | Система определяет, въехала машина в заданную область или выехала из неё |
| Users | Пользователи и роли | Администратор управляет доступом: Admin, Dispatcher, Driver, Client |
| Audit Logs | История изменений данных | Можно увидеть, кто, когда и что изменил |
| Webhooks | Интеграции с внешними системами | При событии TMS может сама отправить HTTP-запрос другой системе |
